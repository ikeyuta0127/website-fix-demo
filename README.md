# 壊れたサイトの修正デモ

架空のカフェサイトを題材にした、ウェブサイト修正・保守のポートフォリオ用サンプルです。
**実在のクライアント案件ではありません。** 不具合はすべて意図的に再現したものです。

## 見せたいこと

「新しく作れる」だけでなく、「既存サイトの不具合を調べて、最小限の変更で直し、直ったことを確認できる」ことを見せるためのリポジトリです。

## 使い方

依存ライブラリなし。ブラウザでファイルを開くだけで動きます。

- 修正版: `index.html`
- 壊れた版（比較用）: `broken.html`
- 動作チェック表: `CHECKLIST.md`

GitHub Pagesに公開する場合は、公開後のトップページが修正版になります。
壊れた版は `https://<ユーザー名>.github.io/website-fix-demo/broken.html` で見られます。

## 不具合一覧と修正内容

| # | 不具合（壊れた版） | 原因 | 修正（修正版） |
|---|---|---|---|
| 1 | スマホで横スクロールが出て、メニューカードが画面からはみ出す | `viewport` がなく、幅が `1100px` 固定で、カードが折り返さない | `viewport` を追加。幅は `max-width: 1100px` + `width: 100%` にし、カードを `flex-wrap` + メディアクエリで1列化 |
| 2 | スマホのハンバーガーメニューが開かない。コンソールにエラーが出る | JSが存在しないID `menuBtn` を探していて `null.addEventListener` で止まる | ボタンの実際のID `menuButton` を取得し、開閉クラスと `aria-expanded` を切り替える |
| 3 | お問い合わせフォームが空でも、メールアドレスが変でも送れてしまう | バリデーションがなく、送信を止める処理もない | 名前・メールアドレス・内容をチェックし、エラー文を項目の下に表示。問題がある場合は送信を止める。問題がなければ送信完了メッセージだけ表示する（実際には送信しません） |
| 4 | 注文数の合計金額がおかしい。例：500円×2個が「5002円」になる | 単価が文字列のまま `+` でつながれている | `Number()` に変換してから掛け算する |
| 5 | 「メニュー詳細」リンクが404、店内写真が表示されない | 存在しない `menu.html` と `images/photo-missing.jpg` を参照し、altも空 | リンク先をページ内の `#menu` に修正。写真は同梱の `images/cafe.svg` を参照し、altを付ける |

## 修正の方針

- 壊れている箇所だけを直し、デザインや構成を大きく変えていません。
- 修正のたびに `CHECKLIST.md` の項目で確認しています。
- 壊れた版は `broken.html` / `css/broken.css` / `js/broken.js` に残してあるので、修正前後をそのまま比べられます。

## ファイル構成

```
index.html          修正版トップページ
broken.html         壊れた版（比較用）
css/style.css       修正版のCSS
css/broken.css      壊れた版のCSS
js/script.js        修正版のJS
js/broken.js        壊れた版のJS（不具合あり）
images/cafe.svg     店内写真の代わりのイラスト
CHECKLIST.md        納品前チェック表
```
